An academic front-end project built using semantic HTML5, CSS3, and JavaScript.

The project was developed with accessibility in mind, ensuring compatibility with screen readers for visually impaired users.

The CSS (style.css) was designed to create a clean and smooth visual aesthetic.

Bootstrap was utilized alongside JavaScript (app.js).

The main page (index.html) introduces an NGO.

The secondary page (projetos.html) showcases the organization's charitable projects.

The third page (cadastro.html) allows volunteers to sign up and make financial contributions.
